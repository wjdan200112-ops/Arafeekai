# أرافيك ذكاء | Aravic AI

منصة عربية للذكاء الاصطناعي والتقنية وصناعة المحتوى.

## التقنية
- Next.js App Router + TypeScript
- Vercel للاستضافة وواجهات API
- Supabase لقاعدة البيانات والمصادقة
- تكاملات Facebook Pages وX الرسمية (من جهة الخادم فقط)

## التشغيل
1. انسخ `.env.example` إلى `.env.local`.
2. أضف رابط مشروع Supabase ومفتاح anon.
3. نفّذ `npm install` ثم `npm run dev`.
4. نفّذ ملف `supabase/schema.sql` في SQL Editor داخل Supabase.

## الأمان
- النشر الاجتماعي يتطلب موافقة صريحة قبل التنفيذ.
- لا تضع رموز وصول Facebook أو X أو مفتاح Supabase service role في كود المتصفح.
- لا تنشئ سياسات كتابة عامة في قاعدة البيانات.
- يلزم إعداد صلاحيات المستخدمين قبل فتح لوحة الإدارة.

## المنجز في هذه المرحلة
- واجهة رئيسية عربية متجاوبة بتصميم فاخر.
- نقطة فحص API على `/api/health`.
- مخطط أولي لقاعدة البيانات: المستخدمون، المقالات، الحسابات الاجتماعية، والمنشورات.
- النشر الآمن مؤجل إلى ما بعد إعداد المصادقة والمراجعة.
